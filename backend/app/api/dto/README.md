# backend/app/api/dto

Pydantic-модели контрактов HTTP API (вход/выход). Роуты и сервисы работают с DTO, не отдают ORM наружу.

## Содержимое

Пока пусто. Ожидаются модули вроде:

- сделки / состояния FSM
- подтверждения оператора (ack/reject)
- загрузка метаданных чеков
- health / служебные ответы
