# AutoSpread

Полуавтоматическая система P2P-арбитража USDT на Bybit (Telegram Mini App + backend).

## Содержимое репозитория

| Папка | Назначение |
| --- | --- |
| [zdocs/](zdocs/) | ТЗ, C4, описание сущностей БД |
| [backend/](backend/) | Серверная часть (Python, Poetry, Dishka, SQLAlchemy, Alembic) |
| [frontend/](frontend/) | Telegram Mini App (пока заготовка) |
| [docker/](docker/) | Заметки по Docker-инфре |
| [scripts/](scripts/) | Скрипты уровня репо (например redis-cli) |
| [docker-compose.yml](docker-compose.yml) | Postgres 16 + Redis 7 |

Каждая кодовая папка содержит свой `README.md` с актуальным содержимым — обновлять по ходу разработки.
