# Обозначения C4 / Context

По легенде GetAnalyst / [гайду C4](https://habr.com/ru/articles/1082254/).

## Типы элементов

| Элемент | Подпись в нотации C4 | Цвет | Назначение |
| --- | --- | --- | --- |
| Person | `[Person]` | синий `#08427B` | Пользователь наших приложений |
| Person (внешний) | `[Person]` | серый `#8C8596` | Не использует наши приложения |
| Software System | `[Software System]` | синий `#1168BD` | Моделируемая система целиком |
| Software System (внешний) | `[Software System]` | серый `#8C8596` | Внешняя система / интеграция |

Внешний элемент отличается **цветом**, не другой подписью типа.

## Связи

Сплошная стрелка, подпись — действие; при необходимости протокол (`JSON/HTTPS REST`, `Bot API`).

## Заголовок

```text
[System Context] AutoSpread
```

## Mermaid в PyCharm

В блоках диаграммы тип показан как `(Person)` / `(Software System)`: квадратные скобки внутри узла ломают парсер Mermaid.  
Превью: Settings → Languages & Frameworks → Markdown → Mermaid.
