# Обозначения C4 / Container

По легенде GetAnalyst / [гайду C4](https://habr.com/ru/articles/1082254/).

## Типы элементов

| Элемент | Подпись в нотации C4 | Цвет | Назначение |
| --- | --- | --- | --- |
| Person | `[Person]` | синий `#08427B` | Пользователь |
| Container | `[Container]` | синий `#1168BD` | Приложение / сервис (api, bot, worker, gateway, frontend, migrate) |
| Container: Database | `[Container: Database]` | зелёный `#2E7D32` | БД (PostgreSQL, Redis) |
| Container: FileStorage | `[Container: FileStorage]` | зелёный `#2E7D32` | Файлы чеков |
| Software System | `[Software System]` | серый `#8C8596` | Внешняя система |
| System Boundary | рамка | — | Граница AutoSpread |

## Связи

Действие + протокол, например: `Вызывает API JSON/HTTPS REST`, `SQL asyncpg`, `Bot API`.

## Заголовок

```text
[Container] AutoSpread
```

## Mermaid в PyCharm

Типы в узлах — в круглых скобках `(Container)`, иначе `[]` ломает парсер.  
Превью: Settings → Languages & Frameworks → Markdown → Mermaid.
